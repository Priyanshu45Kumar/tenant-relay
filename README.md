# TenantRelay

TenantRelay is a multi-tenant SaaS platform for secure and reliable webhook delivery.

## Core Features

- Multi-tenant workspaces
- Team and role management
- API-key authentication
- Event publishing
- Webhook endpoint management
- Background delivery processing
- Automatic retries
- HMAC signatures
- Delivery monitoring
- Failed webhook replay

## Technology Stack

### Backend

- Node.js
- Express.js
- TypeScript
- MongoDB
- Mongoose
- Zod
- JWT

### Background Processing

- Redis
- BullMQ

### Frontend

- React
- TypeScript
- Tailwind CSS
- TanStack Query
- Axios
